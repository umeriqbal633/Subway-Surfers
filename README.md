# Subway-Surfers
Subway Surfers 2D in C++/SFML: A simple endless runner using OOP with states, lane-switching controls, dynamic obstacles, power-ups, speed scaling, pausing, and high-score saving. Built with polymorphic entities and a custom template list for game objects.
# Core FeaturesState Management: The game transitions between STATE_MENU, STATE_GAME, and STATE_GAMEOVER.Controls: The player can jump (W), slide (S), and switch between three lanes (A/D). Movement is governed by basic Newtonian physics (gravity $= 0.8f$) for the jump arc.Dynamic Track: The TrackManager randomly spawns various obstacles (Train, Barrier, Cone, Fence) and power-ups at timed intervals.Difficulty: The game speed increases dynamically from an initial $3.0f$ up to a cap of $15.0f$.Power-Ups: Collectible items include the Shield, Magnet, Double Coin, and Jetpack, each applying a distinct, timed effect.Persistence: High scores are saved to and loaded from a local highscore.txt file by the ScoreManager.⚙️ Technical Architecture (OOP Design)The design is built on OOP principles to ensure maintainability and scalability:Inheritance and Polymorphism:Hazards inherit from the Obstacle base class.Collectible effects inherit from the PowerUp base class.The TrackManager processes these entities polymorphically (e.g., calling applyEffect(Player* p) on a base PowerUp* pointer).Template Usage: A custom GameList<T> template class is implemented to provide dynamic array functionality. This template is used by the TrackManager to safely manage collections of all game entities (Obstacle*, Coin*, PowerUp*).🚀 Building the ProjectThis project requires the SFML library (Simple and Fast Multimedia Library).Dependencies:C++ Compiler (supporting C++11 or later)SFML 2.5+
